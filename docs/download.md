# Download Markon

This permanent page resolves the current stable GitHub release when it opens,
then selects the installer that matches your operating system and CPU
architecture. Use **Other platforms / architectures** if automatic detection
does not match your system.

<DownloadButton />

The complete asset list and release notes remain available on
[GitHub Releases](https://github.com/kookyleo/markon/releases/latest).

## Code signing policy

Markon release artifacts are built from the public source code and checked-in
build scripts in the
[`kookyleo/markon`](https://github.com/kookyleo/markon) repository using
[GitHub Actions](https://github.com/kookyleo/markon/actions). Only artifacts
built from this repository's release workflow are eligible for signing.

Free code signing provided by [SignPath.io](https://about.signpath.io/),
certificate by [SignPath Foundation](https://signpath.org/).

- **Committer and reviewer:** [Leo Kwoc (`kookyleo`)](https://github.com/kookyleo)
- **Approver:** [Leo Kwoc (`kookyleo`)](https://github.com/kookyleo)
- **Approval:** every release signing request requires manual approval by the
  approver.
- **Privacy:** see Markon's
  [Data and privacy](https://github.com/kookyleo/markon#data-and-privacy)
  statement. Markon does not transfer workspace contents to other networked
  systems unless the user explicitly enables and configures a feature that
  requires it.

## 下载说明

本页面打开时会实时读取 GitHub 最新稳定版，并按当前操作系统与 CPU
架构选择安装包。自动识别不准确时，请展开“其他平台 / 架构”手动选择。

Markon 的发布产物由公开源码和仓库内构建脚本通过 GitHub Actions
生成；每次签名都需要审批者手动批准。免费代码签名由
[SignPath.io](https://about.signpath.io/) 提供，证书由
[SignPath Foundation](https://signpath.org/) 提供。
