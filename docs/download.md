## Code signing policy

Markon release artifacts are built from the public source code and checked-in build scripts in the [`kookyleo/markon`](https://github.com/kookyleo/markon) repository using [GitHub Actions](https://github.com/kookyleo/markon/actions). Only artifacts built from this repository's release workflow are eligible for signing.

Free code signing is provided by [SignPath.io](https://about.signpath.io/), with a certificate from [SignPath Foundation](https://signpath.org/).

- **Committer and reviewer:** [Leo Kwoc (`kookyleo`)](https://github.com/kookyleo)
- **Approver:** [Leo Kwoc (`kookyleo`)](https://github.com/kookyleo)
- **Approval:** every release signing request requires manual approval by the approver.
- **Privacy:** see Markon's [Data and privacy](https://github.com/kookyleo/markon#data-and-privacy) statement. Markon does not transfer workspace contents to other networked systems unless the user explicitly enables and configures a feature that requires it.
